# Part 1 · Ad-hoc（baseline）

這個資料夾示範「**還沒有 skill**」的狀態：

- `prompt.md` — 你每次都要手動貼的一長串指示。
- `sample_input.txt` — 一份雜亂的會議記錄，當測試素材。

做法：把 `prompt.md` 的指示 + `sample_input.txt` 的內容貼給 AI，看它產生摘要。

會動，但每次重貼、結果不一致、精確欄位靠模型用眼睛抓 —— 這正是 Part 2 要用一個 Skill 解決的。

→ 看 `../skills/structured-summary/`（Part 2 的成品）與 `../docs/08-from-prompt-to-skill.md`（對照課）。
