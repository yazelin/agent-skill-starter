# Part 1 baseline：沒有 skill，每次用 ad-hoc prompt

這是「還沒做成 skill」的做法 —— 每次要整理筆記，就把下面這一整段貼給 AI，後面接上你的原始文字。

```
請把我接下來貼的文字整理成結構化摘要，格式固定如下：
## 摘要
**重點**（3–5 條，你歸納）
**待辦**（逐條列出，含負責人與日期）
**相關日期**（全部抓出來）
**提及的人**（@ 開頭的人名）
**關鍵數字**（含單位的數字，例如金額、數量、百分比）

注意：日期、人名、待辦、數字要「完整不漏、每次一致」。

原始文字：
<在這裡貼上你的筆記>
```

試試看：把這段 prompt + `sample_input.txt` 的內容貼給 AI。

## 為什麼這樣不夠好（Part 2 要解決的痛點）

- **每次都要重貼**這一長串指示，換台電腦、換對話就要再找一次。
- **結果不一致**：同樣的文字，今天抓到 5 個數字、明天抓到 4 個；格式偶爾跑掉。
- **精確的活靠 LLM 眼睛**：日期、金額、@提及這種「該完整不漏」的東西，模型偶爾會漏或看錯。
- **不會自動觸發**：你得記得「喔這件事我有一套做法」，AI 不會主動套用。

Part 2 把這套做法**打包成一個 Skill**：寫一次、自動觸發、精確的部分交給腳本。
