Agent Skill 入門模板

從每次重貼的 ad-hoc prompt，到一個會自動觸發的 Agent Skill。

核心心法：需要判斷的留給模型，需要精確的交給腳本。日期、@提及、金額這種「該完整不漏、每次一致」的活，不該靠模型用眼睛抓。

# Part 1 baseline：每次重貼一長串 prompt
「請把文字整理成固定格式…日期/人名/數字要不漏」
痛點：重貼、結果不一致、精確欄位靠眼睛抓、不會自動觸發

# Part 2：打包成 Skill，自動觸發
skills/structured-summary/
SKILL.md ← frontmatter 自動觸發
scripts/extract.py ← 確定性抽取
references/format.md ← 輸出格式

# 模型寫「重點」，腳本給 dates/mentions/todos/numbers

這個模板解決什麼？

  • Part 1 重現「沒有 skill」的痛：每次重貼、結果不一致、精確欄位靠模型眼睛抓
  • Part 2 把同一套做法打包成 Skill：寫一次、自動觸發
  • SKILL.md 的 YAML frontmatter(name / description)讓 skill 被發現與觸發
  • scripts/extract.py 做確定性抽取：dates / mentions / todos / numbers，同輸入同輸出
  • references/format.md 用 progressive disclosure，需要時才載入格式細節
  • 免 key 確定性測試：驗 frontmatter + 引用檔存在、跑腳本斷言抽取
