# 摘要輸出格式

固定用這個版面，順序與標題不要改：

```
## 摘要

**重點**
- （你自己讀完內容歸納 3–5 條）

**待辦**
- （逐條來自 extractor 的 todos；若該條含 @人 或日期，一併保留）

**相關日期**
- （extractor 的 dates）

**提及的人**
- （extractor 的 mentions，前面補回 @）

**關鍵數字**
- （extractor 的 numbers，含單位）
```

## 為什麼分這幾欄

- `重點` 需要理解與取捨 → 交給 LLM。
- `待辦 / 日期 / 提及 / 數字` 要「完整、不漏、每次一致」→ 交給 `scripts/extract.py`。

這就是 skill 設計的核心:**把需要判斷的留給模型，把需要精確的交給腳本。**
